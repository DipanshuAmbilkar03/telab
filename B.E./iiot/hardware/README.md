# Actual hardware versions

Real-hardware version of every IIOT experiment: each folder has the Arduino sketch (.ino) and a README with the manual's hardware list and step-by-step connections (pins, power, and how to run it).

Wi-Fi sketches (Exp 3 and 4) have a placeholder hotspot name "YourHotspot" in the code; change it to your own mobile hotspot before uploading. Exp 5 is an Excel data-analysis practical; the folder holds the data and the Python version of the same steps.
