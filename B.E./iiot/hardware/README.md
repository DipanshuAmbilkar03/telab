# Actual hardware versions

Real-hardware version of every IIOT experiment: each folder has the Arduino sketch (.ino) and a README with the manual's hardware list and step-by-step connections (pins, power, and how to run it). Exp 1 to 4 folders also have the wiring as separate files: `connections.txt` (plain pin-to-pin list), `diagram.json` (the same circuit diagram as the Wokwi version), and `circuit_diagram.png` (a visual image of the circuit with labelled wires). All connections in one place: see `CONNECTIONS.md` in this folder. Exp 5 has no circuit; its visual images are the temperature and humidity graphs (PNG files) in its folder.

Wi-Fi sketches (Exp 3 and 4) have a placeholder hotspot name "YourHotspot" in the code; change it to your own mobile hotspot before uploading. Exp 5 is an Excel data-analysis practical; the folder holds the data and the Python version of the same steps.
