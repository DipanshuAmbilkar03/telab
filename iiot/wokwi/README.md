# Wokwi versions

Simulation version of every IIOT experiment: each folder has the Arduino sketch (.ino, folder name = sketch name) and `diagram.json` with the Wokwi connections. Create a Wokwi project, add the parts, and paste the sketch, or import the diagram to rebuild the circuit.

Wi-Fi sketches (Exp 3 and 4) use the open "Wokwi-GUEST" network. Exp 5 is an Excel data-analysis practical, it has no circuit; the folder holds the data and the Python version of the same steps.
