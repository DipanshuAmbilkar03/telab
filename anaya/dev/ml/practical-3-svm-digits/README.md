# Practical 3: SVM Classification of Handwritten Digits (simple version)

## Aim
Classify images of handwritten digits (0-9) using a Support Vector Machine.

## Problem Statement (from the syllabus)
Implementation of Support Vector Machines (SVM) for classifying images of handwritten digits into their respective numerical classes (0 to 9).

## Steps followed
1. Load the sklearn digits dataset (1797 images of 8x8 pixels).
2. Split into train (80%) and test (20%).
3. Train an SVC classifier.
4. Evaluate with accuracy, classification report and confusion matrix.

## Output
- Accuracy around 98-99% on the test set; the confusion matrix shows which digits get confused with each other.
